ExSoil: CTSM + NEON Analysis Environment

A containerized JupyterLab platform for running NCAR's Community Terrestrial Systems Model (CTSM) against NEON tower observations — with built-in Kalman-filter calibration, plant-functional-type perturbation experiments, and S3-backed forcing pipelines.

What this is

A reproducible research environment that packages NCAR's cesm-lab-neon image with custom analytics utilities and guided notebooks. Researchers can run NEON-site simulations and calibrate them against tower observations without manually building the CTSM/CIME toolchain.

CTSM simulations

One-command transient runs for any of 47 NEON sites via run_neon_v2.py, with optional S3-backed forcing data and counterfactual transforms (scaling, seasonal, noise).

PFT perturbation

Shift cover between plant functional types in the surface dataset and compare ecosystem-level responses against a control run.

Calibration & misfit

Kalman-filter calibration of model output against tower observations, with built-in residual diagnostics and metrics.

Interactive hubs

Guided notebooks for data exploration (Data Hub), experimental design (Design Hub), and modeling (Modeling Hub).

How to access

If you're a user: click Launch the Tool above, sign up with a username and password, and an administrator will approve your account. Once approved you'll get your own JupyterLab session inside a fresh CTSM container with persistent storage.

If you'd rather run it locally with Docker:

docker run --rm -p 8888:8888 ghcr.io/uw-madison-dsi/exsoil-nsf-prototype-refactor:latest

Then open http://127.0.0.1:8888/lab in your browser. The base image is ~2 GB; the first pull takes a few minutes.

Tech stack

CTSM 5.1 JupyterLab JupyterHub xarray Docker GHCR GitHub Actions CI Caddy / Let's Encrypt

Source code, Dockerfile, and CI configuration live in the public repository. Container images are published to ghcr.io/uw-madison-dsi/exsoil-nsf-prototype-refactor on every push to main.

For administrators

To run a self-hosted JupyterHub instance using this image (the same configuration that powers the Launch button above):

git clone https://github.com/UW-Madison-DSI/exsoil-nsf-prototype-refactor.git
cd exsoil-nsf-prototype-refactor/deploy/jupyterhub
cp .env.example .env
# edit JUPYTERHUB_ADMIN_USERS in .env
docker compose up -d --build

Full deployment walkthrough including HTTPS via Caddy and Let's Encrypt: deploy/jupyterhub/README.md.
